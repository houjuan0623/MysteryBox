# 安全、隐私与威胁模型

> 恢复版（2026-10-14）：根据旧任务正文与修订重建。下述代码/接口为恢复目标，需对照新工程验证。历史通过记录不等于当前恢复目录通过。

范围包括浏览器、Next代理、NestJS、Store及PayPal/Vercel AI Gateway/Resend。本文是工程分析，不是法律合规证明。

管理端为独立Next.js应用（shadcn/ui + Tailwind），但权限必须由NestJS服务端验证，隐藏导航不等于授权。管理员统计只基于第一方数据，demo交易不得冒充真实收入；零数据不能用虚构数字填充。

## 1. 资产和边界

资产：付款金额与归属、Box/目标、邮箱、会话、匿名token、供应商秘密、历史收藏。不可信：客户端JSON/URL/key/cookie/goal、模型输出、未验签事件、第三方资料。可信规则在服务端配置、核验目录、领域层与数据库约束；UI不授予权限。

管理员授权使用 Mongo 运维 CLI，对已验证账户 grant/revoke；无浏览器赋权或默认管理员。报告每次读当前服务端角色，撤权不能只隐藏菜单。APP_URL/ADMIN_APP_URL 均是精确来源 allowlist，不能改成任意 CORS。

## 3. 数据流

浏览器向MysteryBox发送兴趣、目标、可选结果邮箱、登录邮箱与收藏。模型调用发送兴趣/目标/目录到配置的Vercel网关及下游模型，不需要邮箱。PayPal收到订单/金额/说明/回站地址，支付资料在其界面处理。Resend收到邮箱及验证码或Box正文。官网外链不自动上传brief或邮箱。

自由目标可能被用户写入秘密，必须提示并披露接收方/用途；不能声称内容不离开系统。定义保留、删除、支持流程。store:false不构成所有供应商留存的承诺。

第一方统计分开处理必要业务记录与可选浏览事件。订单/Box/账户总量来自持久化业务状态；可选事件不写账户 ID，无 visitor header 时不采集，遵守前台关闭与 Do Not Track。可选事件保留 30 天并每小时清理，不等于删除必要账户或财务记录。

## 4. 特殊MVP风险

### 代理信任

TRUSTED_CLIENT_IP_HEADER仅接受x-real-ip/x-vercel-forwarded-for和合法单IP。ingress必须覆盖该头并阻止直连Web。PROXY_SHARED_SECRET独立共享，时间戳签名60秒。它只标识限流主体，不是交易防重放凭证。开发mb_visitor可清除，只为隔离演示配额，不是防刷保证。

### 匿名凭证

资源token无独立TTL/撤销，sessionStorage可被同源脚本读取。HttpOnly账号会话不能保护它；禁止进日志、分析、公开URL。全局SESSION_SECRET轮换会使全部派生访问token/码失效，应提供恢复方案。

### 外部状态和幂等

DB回滚不会撤销capture或邮件。响应不明确应查原provider订单，不因本地pending就再次收费。供应商幂等期限有限；邮件自动恢复限定创建23小时内、总尝试5次，旧任务人工核对。不能承诺严格端到端exactly-once。

### 存储与生命周期

Memory只演示，重启丢失；MongoDB使用replica-set事务、唯一(kind,key)和业务竞争guard。不得自动重跑含外部调用的事务闭包；竞争、commit不确定、guard恢复和多实例必须真库验证。长期采用短事务+任务lease/outbox演进。过期记录不等于删除；当前未完成完整retention、导出和账号删除。财务记录保留策略由责任人决定。

### 退款与争议

成功capture处理不等于完整付款生命周期。退款/撤销/拒付/争议需明确人工支持与审计，不能对用户承诺不存在的自动退款。

## 5. 发布门槛

HTTPS与私网，可信入口和不可绕过IP来源；公开生产无demo和developmentCode；数据库最小权限/加密备份/恢复演练；秘密管理无Git/前端/日志泄漏；预算和域/webhook设置；依赖/secret扫描；跨账号和负向支付测试；paid-but-not-ready/队列/邮件/成本告警；停付、回滚、对账和支持责任人。

## 6. 事件处置

疑似重复收费或不可交付先暂停新增付费入口，不批量重放请求；记录request/订单/provider ID与时间，不收集完整凭证；官方渠道确认资金，分开处理用户影响和恢复；必要时轮换泄露秘密并评估会话/token；sandbox重现修复再恢复入口；记录范围、处置与通知义务。

依赖以lockfile复现，升级后typecheck/测试/构建/E2E。mock不能替代真实契约。发布前复核第三方目录和条款。

## 7. MCP 追加边界

MCP 默认无路由，独立 bearer 摘要鉴权和最小 scope；不继承 Web/admin 会话。默认 loopback、严格 Host/Origin 和 16 KiB 入口限制；远程开启需可信 HTTPS ingress 与独立授权。工具只返回汇总或该 principal 私有草稿，禁止任意 Mongo 查询、shell、用户导出、支付/退款、真实模型/邮件和发布动作。

草稿正文是未受信任数据，不是后续执行指令。创建草稿、幂等回执和成功审计原子提交；审计失败不能报成功。审计不记录 bearer、正文、邮箱或原始 IP，但完整审计保留策略仍待运营确定。配置凭据、持久客户端访问及真实远程部署是单独授权与验收事项。
