## 阶段2：按证据启动，目前延期

| 项目          | 启动依据            | 延期原因                     |
| ------------- | ------------------- | ---------------------------- |
| 订阅          | 持续复用价值        | 一次有用不等于订阅需求       |
| 推荐画像/算法 | 充分合法反馈        | 冷启动复杂度无收益证明       |
| 社区          | 活跃与审核资源      | 治理/隐私成本                |
| Agent代执行   | 清楚权限和失败成本  | 推荐不授予操作权限           |
| 自动增长      | 人工内容有稳定效果  | 自动化会放大低质量和平台风险 |
| 原生App       | Web无法满足核心任务 | 避免双产品维护               |

## 增长与目录

TikTok/X/Newsletter先人工验证。原方案账号、频率、自动发布都是待决策项；本工程没有创建账号、发布、订阅用户或联系第三方。

目录扩容先补场景，不能堆数量。新记录要官方来源、能力/限制/日期；停用工具须保留历史兼容。商业关系需要披露，不能广告排序伪装质量评分。

## 暂停条件

用户误解购买包含第三方许可证；付款不稳定交付；仍需用户重做大部分研究；免费模型成本失控；无复访价值却准备自动续费。

下一次迭代先验证真实适配器，再关闭恢复/事务/邮件可观测性缺口，人工评估结果，最后决定价格实验和平台化。
